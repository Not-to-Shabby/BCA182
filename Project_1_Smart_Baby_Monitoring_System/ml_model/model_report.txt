goal: lift the v5 model's frozen-test cry recall (0.335, F1 0.480, confuser FP 7.7%) under the

tuning on VAL only; no crying_baby clip is ever trained on).
root cause addressed: the 29-feature front end summarizes away temporal dynamics -
feature-set v2 appends 34 dynamics features to the unchanged 29 (63 total): per-frame
MFCC deltas (edge-replicated first difference, mean+std), log-energy delta mean+std,
and per-frame spectral centroid/rolloff(0.85)/flatness mean+std (extract_features.py,
mirrored + parity-tested in src/audio_features.c).
levers: (1) feature-set v2 front end, (2) the v5 wave-level augmentation of TRAIN
windows only (augment.py, reused unchanged - same seeds, same recipes), (3) a seeded
model-type sweep (RF 12x7 / RF 30x8 / ET 30x8 / ET 12x7), (4) cry-vote-share threshold
    swept 40..85 with the 10% FP gate on the CONFUSER split (the task's target metric); the raw VAL
non-cry FP rate is reported at every sweep point (it runs higher: fold-4 ambience covers all 40 ESC-50 classes,
while the confuser split and the frozen-test non-cry subset are the deployment-relevant FP populations).
augmentation (train cry windows): REAL ESC-50 fold 1-3 non-cry ambience mixed at SNR 10-25 dB (p=0.5, cry dominant; white/pink synthetic noise SNR 5-20 dB otherwise), 2-3-tap room reverb (p=0.7), first-order lowpass 2500-7000 Hz (p=0.6), volume -6..+14 dB with a +10..+20 dB loud branch (p=0.3, mirrored on non-cry), pitch/speed +/-10% (p=0.5, per file), 50 Hz hum -32..-22 dB rel (p=0.25)
augmentation (train non-cry windows): synthetic noise + volume only (same loud branch), 100% of windows
variants per cry clip: 2 (cached in features_aug_cache.npz, seeded per file)
threshold tuning uses a stress-val cry proxy: the deployment channel (always lowpass 2.5-5 kHz, real-noise mix SNR 0-10 dB) applied to VAL cry windows only - cry-side F1 mixes raw + stress val cries, the FP gate stays on raw VAL non-cry + confusers
firmware rule replicated: cry iff strict majority votes CRY AND cry vote share >= threshold (src/cry_task.c)
